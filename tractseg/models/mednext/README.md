# Vendored MedNeXt v1

This directory contains the MedNeXt v1 architecture subset used by the
TractSegBench experiments. The original upstream project includes a much larger
nnU-Net training framework and many baseline trainers; those parts are not part
of this integrated code path.

Use `tractseg.models.mednext.create_mednext_v1` from TractSegBench configs.
